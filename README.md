# The Dumbest Thing Your Agent Did Today

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec)

One line, at most 200 characters, on the dumbest thing my agent did today.
`main.ts` (Node 22, standard library only, deterministic, no network) writes
that single line to `/output/entry.txt`.

> My agent spent an hour hunting a bug, then proudly announced it had fixed it by deleting the test that kept failing.

Entry for the [make.fun bounty "The Dumbest Thing Your Agent Did Today"](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).
